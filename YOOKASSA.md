# YooKassa — настройка и работа с платежами

## Технический чеклист (один раз при настройке)

### 1. Переменные окружения (.env на сервере)

```env
YOOKASSA_SHOP_ID=ваш_shopId
YOOKASSA_SECRET_KEY=live_...  # Секретный ключ из ЛК → Настройки → Ключи API
```

### 2. Webhook в ЛК YooKassa

Настройки → Уведомления → URL для уведомлений:

```
https://prepstats.pro/users/payment/webhook/
```

Включить только событие: **payment.succeeded**

### 3. Интеграция с «Мой налог» (рекомендуется)

ЛК YooKassa → Настройки → «Мой налог» → подключить.

После этого YooKassa будет автоматически:
- регистрировать каждый платёж в ФНС
- отправлять чек покупателю на email, который он вводит на странице оплаты

---

## Алгоритм при каждой оплате

### Технически (происходит само)

1. Пользователь нажимает «Купить» → редирект на страницу YooKassa
2. Пользователь вводит карту и оплачивает
3. YooKassa шлёт webhook на сервер → подписка активируется автоматически
4. Пользователь получает письмо от PrepStats с подтверждением и датой окончания

### Формально (твои действия)

**Если интеграция с «Мой налог» настроена:**
- Ничего делать не нужно. YooKassa сама регистрирует доход и отправляет чек покупателю.

**Если интеграция НЕ настроена:**
- Открыть приложение «Мой налог» (или lknpd.nalog.ru)
- Нажать «Новый чек»
- Заполнить:
  - Услуга: «Базовая подписка PrepStats на 30 дней» / «Премиум-подписка PrepStats на 30 дней»
  - Сумма: 399 ₽ / 799 ₽
  - Email покупателя — опционально (взять из ЛК YooKassa → Операции)
- Выдать чек → доход зафиксирован в ФНС

> Делать это нужно на каждый платёж. При росте числа пользователей ручная выдача быстро станет неудобной — лучше настроить интеграцию сразу.

## Где смотреть платежи

| Что нужно | Где найти |
|---|---|
| Список всех платежей | ЛК YooKassa → Операции |
| Статус конкретного платежа | ЛК YooKassa → Операции → детали |
| Логи webhook на сервере | `docker compose logs -f web` |
| Список подписок в БД | Django admin → Подписки |
| Список платежей в БД | Django admin → Платежи |

## Если что-то пошло не так

**Webhook не сработал** (пользователь оплатил, но подписка не активировалась):
1. Проверить логи: `docker compose logs web | grep webhook`
2. В ЛК YooKassa → Операции найти платёж, скопировать `payment_id`
3. Вручную в Django shell:
```python
from users.models import Payment
from users.services import activate_subscription

p = Payment.objects.get(yookassa_payment_id='2a000000-...')
p.status = 'succeeded'
p.save()
activate_subscription(p.user, p)
```

**Пользователь оплатил, но попал на страницу «Платёж обрабатывается»:**
- Webhook ещё не пришёл (обычно приходит за секунды, максимум минута)
- Попросить пользователя обновить страницу через минуту
- Если через 5 минут не активировалась — смотреть логи (см. выше)
