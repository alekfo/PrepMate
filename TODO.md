## Технический долг

- [ ] `interviews_used` в `start` view обновляется через `update()` без `F()` — потенциальный race condition при одновременных запросах одного пользователя.
- [ ] Старые сессии не имеют `weakness_tags` / `strength_tags` в `Feedback` (поля пустые по умолчанию) — блок «Динамика навыков» для них будет пустым. Решение: либо мириться, либо сделать ретроспективную оценку тегов.
- [ ] `SessionAdvice` генерируется при каждом первом визите синхронно в request/response цикле — при большом числе сессий без советов страница будет долго грузиться. Решение: фоновая задача (Celery) или пагинация генерации.
